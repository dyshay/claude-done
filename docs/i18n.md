# Internationalization (i18n)

claude-done supports 8 languages.

## Supported languages

| Code | Language   |
|------|------------|
| en   | English    |
| fr   | French     |
| es   | Spanish    |
| de   | German     |
| pt   | Portuguese |
| it   | Italian    |
| ja   | Japanese   |
| zh   | Chinese    |

## How it works

All user-facing strings are stored in `locales/<lang>.json`. The `t()` function resolves keys using dot notation with placeholder support:

```js
t('notification.title', { project: 'myapp', type: 'Rust' })
// => "myapp (Rust) - Task complete"
```

## Adding a new language

1. Copy `locales/en.json` to `locales/<code>.json`
2. Translate all string values
3. Add the code to the `SUPPORTED` array in `src/i18n.js`

## Character encoding

Locale files avoid accented characters for Windows compatibility (e.g., "termine" instead of "termine" with accent). Japanese and Chinese files use native characters as they don't cause encoding issues on their target platforms.
